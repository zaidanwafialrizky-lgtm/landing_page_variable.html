01 — KONSEP DASAR

Variable itu apa, sih?

Anggap variable seperti kotak berlabel yang menyimpan data agar bisa dipakai kembali oleh program.

A / VARIABLE
nama
"Zaidan"

Tempat menyimpan data

Nama, umur, nilai, dan informasi lain bisa disimpan dalam variable.

let nama = "Zaidan";
B / LET
↻

Nilainya bisa berubah

Gunakan let saat data mungkin perlu diperbarui selama program berjalan.

let nilai = 80;
nilai = 90;
C / CONST
⌑

Nilainya tetap

Gunakan const saat variable tidak perlu diberi nilai baru.

const sekolah = "SMK";
